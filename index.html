    About WaW Script Placer

    An unofficial community app. Not affiliated with or endorsed by the UGX team.

    A starter mod/map creator for World at War, made by a community member, for the community.

    General generation is 1:1 with UGX Script Placer 2.0.1: the same 18 starter files, contents and map-name/display-name substitutions for Blank, Setup and Custom. This is not a modified starter pack.

    The UI is new, and overwrite handling is fixed: Skip leaves files untouched, Replace replaces them, and Back Up + Replace keeps a backup first.

    The Delete tab lets you review and remove starter files, other map files in the game folder, and the playable copy in AppData separately.

    Prepare your game folder with the Modtools and UGX patch first. This app does not install patches, perks, FX, menus or UGX-MOD, or save game paths in the registry.

    Built with JavaScript, Vite and Tauri. Run from source with npm install then npm run dev . Released executables go beside CoDWaW.exe .

    Created by phil81334 .
    Original starter resources: Treyarch and UGX/community contributors.
